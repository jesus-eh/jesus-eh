## 01 / Engineering focus

I'm a software developer interested in building secure, reliable systems and understanding how software, infrastructure, and security intersect.

My work combines practical development with hands-on experimentation, from self-hosted environments and security monitoring to Python tools and intrusion detection.

- **Backend engineering:** Python, scripting, automation, and software development.
- **Cybersecurity:** Security monitoring, network security, intrusion detection, and offensive security research.
- **Infrastructure & systems:** Virtualization, containers, networking, self-hosted services, and system hardening.
- **Space & satellite security:** Exploring satellite communications, ground segment security, and the cybersecurity challenges of space systems.
- **Aerospace & defense technology:** An interest in secure architectures, resilient communications, and mission-critical infrastructure.
- **Research & experimentation:** Jupyter Notebook, technical analysis, and practical security labs.

I'm particularly interested in the intersection of software engineering, cybersecurity, and resilient systems — from the homelab to the infrastructure supporting space technologies.
